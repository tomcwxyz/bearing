# Bearing

**Find the right AI model for the job.**

Bearing helps you choose an AI model for a particular task. Explain what you need, see a recommendation with meaningful alternatives, and understand the evidence behind it.

[Try Bearing](https://findbearing.org) · [Start with the user guide](user-guide.md)

## What makes it different?

- **Task first:** recommendations start with what you're trying to achieve.
- **Explainable:** inspect trade-offs such as quality, cost, privacy, openness and sustainability.
- **Practical:** run and compare supported models, including local options.
- **Open to challenge:** assumptions, evidence and the methodology can all be questioned.

A ranking score is **not** a probability of success. Bearing keeps model claims, benchmarks, current availability and outcomes distinct.
